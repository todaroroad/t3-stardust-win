# T3 星尘版 v1.2.0

基于官方 T3 Code 截至 2026-11-21 的最新代码（`0.1.11`，提交 `f9b19a7f85`），面向 macOS Apple Silicon。

## 升级前请先看
首次启动 v1.2.0 会把本地数据库从 schema 95 升级到 105。升级后，旧版星尘版（v1.0.x）和更早的官方 T3 Code 将无法读取这份数据。建议升级前先备份 `~/.t3/userdata`。

## 星尘版新增与改进
1. **V18「星舰发射栈」推理强度滑块**：5 档连续飞行与 180ms 升档反馈；羽流与粒子改为预烘焙离屏贴图（每帧渐变对象从约 120–180 个降到 6 个以内），静止 2 秒后停止重绘。
2. **更顺滑的弹窗**：去掉「会话概览 / 令牌与缓存」弹窗的 `filter: blur` 过渡，毛玻璃半径降到 `12px`。
3. **紧凑的模型选择器**：顶部横排提供方标签、固定高度可滚动列表、每个模型显示档位与剩余额度；底部权限胶囊按「自动 / 需审批」着色。
4. **更精简的设置**：移除 Clawd 工作台与「专注对话」；「侧栏分类」并入会话页；更新模式默认「标准 · 手动确认更新」。
5. **应用正名**：统一以 `T3 Stardust.app` 发行。
6. **星尘积木工坊（首期）**：仓库新增 `stardust-kit/`，V16 / V17 / V18 / V19 全套推理滑块，每套附 `demo.html`、独立源码与 AI 改造 Prompt。
7. **修正更新提醒**：版本基线为 v1.2.0，已安装 v1.2.0 的用户不会被反复提示。更新仍为提醒 + 手动下载安装，应用不会自动替换或重启。

## 合并的官方更新
合并了官方 1,073 个提交，包括：Git 性能优化（列分支、推送、查看状态时启动的 git 进程更少）、用量限额行显示消耗速度并可跳转用量页、Mac 原生语音输入（Apple Speech）、聊天表格可复制为 HTML、文件预览新增复制按钮、悬停会话标签显示会话卡片。

## 校验与安装
下载 `T3-Stardust-v1.2.0-macOS-arm64.zip` 与 `SHA256SUMS.txt` 后执行 `shasum -a 256 -c SHA256SUMS.txt`，解压拖入 `/Applications`。公开版为 ad-hoc 签名（未经 Apple 公证），首次打开若被拦截，到 **系统设置 → 隐私与安全性** 点「仍要打开」。
