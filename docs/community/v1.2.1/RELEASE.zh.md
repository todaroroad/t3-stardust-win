# T3 星尘版 v1.2.1

在 v1.2.0 基础上的小版本，数据库不变（仍为 schema 105），可以直接覆盖安装。

## 新增
1. **匿名活跃人数统计（默认开启）**：每天最多发送一次随机安装 ID、版本号、系统和芯片类型，不含聊天、账号、项目或 IP。第一次启动会弹出说明，可直接点「关闭统计」；之后在 **设置 → 关于 →「计入星尘版活跃用户」** 随时开关。网站只公开「近 7 天活跃设备数」。
2. **更新提醒显示版本号**：提醒标题和设置页改为显示「v1.2.2」这样的版本号，不再显示内部排序数字。

## 校验与安装
下载 `T3-Stardust-v1.2.1-macOS-arm64.zip` 与 `SHA256SUMS.txt` 后执行 `shasum -a 256 -c SHA256SUMS.txt`，解压拖入 `/Applications`。公开版为 ad-hoc 签名（未经 Apple 公证），首次打开若被拦截，到 **系统设置 → 隐私与安全性** 点「仍要打开」。
