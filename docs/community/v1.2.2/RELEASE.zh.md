# T3 星尘版 v1.2.2

在 v1.2.1 基础上的更新，数据库不变（仍为 schema 105），可以直接覆盖安装。

## 修复
1. **ChatGPT 登录走系统代理**：开着 Clash 等「系统代理」时，应用后台以前不走代理，国内直连 `auth.openai.com` 会报「Could not reach ChatGPT sign-in」。现在启动时会读取 macOS 系统代理并交给后台使用；你自己设置了 `HTTPS_PROXY` 时以你的为准。仅支持 HTTP/HTTPS 代理，纯 SOCKS 代理不生效。
2. **欢迎页左上角不再压住红绿灯**：首次启动的欢迎页里，额度按钮和窗口的红黄绿按钮重叠的问题已修复。
3. **未登录时不显示空的额度按钮**：还没有任何账号读到额度时，左上角不再显示空的「剩余额度」按钮，登录并读到额度后自动出现。

## 新增
1. **macOS 一键更新**：在 **设置 → 关于** 和新版本提醒里可以直接「更新并重启」：下载、校验 SHA-256 和签名、替换应用、自动重开，失败会自动回滚，旧版本保留在缓存目录的 `update-backup` 里。另有「自动下载更新，下次启动时安装」开关（默认关闭）。**从 v1.2.2 开始生效**，v1.2.1 及更早版本这次仍需手动下载安装。
2. **设置 → 存储与清理**：按固定规则（不是 AI）扫描可以清理的东西，分成「放心清」「看一眼」「只提醒不动」三档。「看一眼」先移到废纸篓，7 天内可撤销；有未提交 git 改动的目录永远不会进「放心清」；删除前可先「抢救」到 `~/文稿/T3 Stardust 抢救/`。如已安装 [Mole](https://github.com/tw93/Mole)，只会调用它的 `mo clean --dry-run` 读取清单。用量页只保留一个「磁盘剩余」入口。
3. **额度条**：当前对话的账号排第一，其余按剩余额度排序；去掉「读数已过期」字样，窗口可见时每 10 分钟自动刷新。

## 校验与安装
下载 `T3-Stardust-v1.2.2-macOS-arm64.zip` 与 `SHA256SUMS.txt` 后执行 `shasum -a 256 -c SHA256SUMS.txt`，解压拖入 `/Applications`。公开版为 ad-hoc 签名（未经 Apple 公证），首次打开若被拦截，到 **系统设置 → 隐私与安全性** 点「仍要打开」。
