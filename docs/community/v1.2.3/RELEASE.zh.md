# T3 星尘版 v1.2.3

性能与界面减负更新。数据库不变（仍为 schema 105），可以直接覆盖安装；v1.2.2 用户可在 **设置 → 关于** 一键「更新并重启」。

## 性能
- **空闲时不再持续重绘**：侧边栏左上角的彩色流光字标以前每一帧都在重绘，实测占用约 30% CPU（界面渲染 + GPU 合计，100% 为一个核心），机器会因此发热。现在改为静态。
- **对话运行时更省**：侧边栏运行状态圆点不再闪烁、正在执行的工具名不再扫光，二者合计约 13% CPU。
- 实测（同一台 Mac，对话运行中）：界面渲染 + GPU 合计从约 52–56% 降到约 4%。

## 界面
- **左上角更安静**：「T3 Stardust」彩色字标改为灰色「T3」加一颗来自应用图标的小紫星，把注意力留给输入框和对话。
- **前进 / 后退箭头**：只在鼠标移到侧边栏时出现（键盘聚焦时也会出现），平时左上角只有红绿灯、折叠按钮和标识。

## 校验与安装
下载 `T3-Stardust-v1.2.3-macOS-arm64.zip` 与 `SHA256SUMS.txt` 后执行 `shasum -a 256 -c SHA256SUMS.txt`，解压拖入 `/Applications`。公开版为 ad-hoc 签名（未经 Apple 公证），首次打开若被拦截，到 **系统设置 → 隐私与安全性** 点「仍要打开」。
